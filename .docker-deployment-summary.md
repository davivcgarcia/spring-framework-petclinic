## 🎯 How to Use

### Pull from ECR:
```bash
# Authenticate
aws ecr get-login-password --region us-east-1 | \
  docker login --username AWS --password-stdin \
  403779000275.dkr.ecr.us-east-1.amazonaws.com

# Pull image
docker pull 403779000275.dkr.ecr.us-east-1.amazonaws.com/atx-containers/virtual-bug-bash:spring-petclinic-latest

# Run container
docker run -d \
  --name petclinic \
  -p 8080:8080 \
  403779000275.dkr.ecr.us-east-1.amazonaws.com/atx-containers/virtual-bug-bash:spring-petclinic-latest

# Access application
open http://localhost:8080
```

### Build locally:
```bash
# Build
docker build -t spring-petclinic:latest .

# Run
docker run -d --name petclinic -p 8080:8080 spring-petclinic:latest

# View logs
docker logs -f petclinic
```
